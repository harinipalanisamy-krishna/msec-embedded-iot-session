# Advanced Embedded IoT with Raspberry Pi — MSEC Mentoring Session

**Resource Person | Value Added Course on Embedded System & IoT**
**Meenakshi Sundararajan Engineering College (Autonomous), Kodambakkam, Chennai | 24th June 2026**

## Overview
Designed and delivered a live technical mentoring session for pre-final year ECE/EIE students — translating advanced embedded IoT concepts into hands-on, real-world learning through a 59+ slide deck, live coding demos, and an interactive audience-engagement segment.

The goal wasn't just to teach — it was to make a room full of engineers *feel* the material: real Python code, a live sensor-to-cloud pipeline, and a moment of genuine surprise that got the whole room talking.

## What's Inside
- 📊 **Full session deck** (59+ slides) — concepts, demos, interactive segments
- 🧠 **"Real or Fake" mentoring segment** — an audience-engagement exercise on emerging IoT applications (IoT toilets, smart contact lenses, sensor-embedded hospital bedsheets) designed to spark curiosity before revealing the real-world answers
- 💻 **Python code** — end-to-end sensor data pipeline to ThingSpeak
- 🔌 **GrovePi demo** — Switch + LED circuit walkthrough
- 📸 **Session photos & recognition**

## Topics Covered
- Raspberry Pi fundamentals for IoT
- GrovePi sensor/actuator integration
- Python-based sensor data handling
- Real-time cloud dashboards with ThingSpeak
- Applied, real-world IoT use cases

## Mentoring Approach
No textbook slides, no theory-only delivery. The session was built around live demonstration and audience participation — designed to hold the attention of 50+ students and turn a technical topic into an interactive experience.

## Audience
Pre-final year ECE/EIE students, MSEC
